# Зависимости для TTS и стенда подбора голоса (tools/voice_lab.py).
#
# Установка (venv на uv — python3-venv на плате отсутствует, нет ensurepip):
#   uv venv ~/models/tts-venv --python 3.10
#   uv pip install --python ~/models/tts-venv/bin/python -r requirements.txt \
#     --extra-index-url https://download.pytorch.org/whl/cpu
#
# ВАЖНО: --extra-index-url .../whl/cpu обязателен. Без него uv ставит
# torch+cu130 и тянет ~2 ГБ бесполезных на ARM nvidia-* библиотек.
#
# Что НЕ нужно:
#   * пакет silero — модель Silero v5_5_ru самодостаточна, загружается через
#     torch.package без него (проверено: TTSModelMultiAcc_v3 грузится);
#   * пакет omegaconf — нужен только старому silero-пакету;
#   * onnxruntime — не для TTS (он для ASR/sherpa-onnx).
#
# Стенд (voice_lab.py) работает БЕЗ torch в режимах list и check —
# их можно запускать на машине без зависимостей.
