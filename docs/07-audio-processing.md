# Обработка аудио

## Зачем обрабатывать

Микрофон пишет звук с артефактами:
- **Низкочастотный гул** (50 Гц и гармоники от сервера, питания USB)
- **Высокочастотное шипение** (>7 кГц, дешёвый USB-АЦП)
- **Неравномерная громкость** (речь тише, шум громче)

ASR-модели обучены на чистой речи, поэтому нужна предобработка.

## Рабочий пайплайн (проверен)

```bash
sox raw.wav ready.wav \
  highpass 300 \
  lowpass 7000 \
  rate -v 16000 \
  norm -3
```

**Что делает каждый шаг:**

| Фильтр | Назначение |
|---|---|
| `highpass 300` | Убирает гул сервера (всё ниже 300 Гц) |
| `lowpass 7000` | Убирает шипение USB (всё выше 7 кГц) |
| `rate -v 16000` | Качественный ресемплинг 48 → 16 кГц |
| `norm -3` | Нормализация до −3 дБ (пик) |

## Проверка результата

```bash
sox ready.wav -n stat 2>&1 | head -12
```

Целевые метрики:

| Метрика | Норма |
|---|---|
| RMS amplitude | > 0.02 |
| Midline amplitude | < 0.05 |
| Maximum amplitude | 0.3–0.9 |
| Rough frequency | 500–3000 |

## Спектрограмма — визуальная проверка

```bash
sox ready.wav -n spectrogram -o spec.png
```

**Правильная запись:**
- Видна «ёлочка» гармоник речи (0–8 кГц)
- Тёмные паузы между фразами
- Нет яркой линии на DC (низ спектрограммы)

**Проблемная запись:**
- Сплошное яркое поле
- Речь едва видна (1–2 кГц)
- Яркая полоса на DC внизу

## Нейросетевые denoiser'ы — не использовать

Проверено на практике:

| Метод | Результат |
|---|---|
| **sox только** | ✅ «алиса включи свет на кухне» |
| sox → GTCRN | ❌ «алиса включи свет на кулке» |
| sox → DPDFNet | ❌ пустая строка |

**Почему:** нейросети рассчитаны на грязный сигнал; на чистом они работают как усилитель ошибок, задавливая форманты речи.

**Когда нейросети нужны:**
- Микрофон в очень шумном месте (улица, кухня с вытяжкой)
- Запись с реверберацией (большая комната)

**Как использовать (если понадобится):**

```bash
# GTCRN
~/sherpa-onnx/build-rknn/install/bin/sherpa-onnx-offline-denoiser \
  --speech-denoiser-gtcrn-model=gtcrn_simple.onnx \
  --input-wav=in.wav --output-wav=out.wav

# DPDFNet
~/sherpa-onnx/build-rknn/install/bin/sherpa-onnx-offline-denoiser \
  --speech-denoiser-dpdfnet-model=dpdfnet_baseline.onnx \
  --input-wav=in.wav --output-wav=out.wav
```

Модели: `gtcrn_simple.onnx` (~524 КБ), `dpdfnet_baseline.onnx` (~8.4 МБ) — из релизов `k2-fsa/sherpa-onnx` → speech-enhancement-models.

## Потоковая запись с фильтром (без промежуточного файла)

```bash
arecord -D plughw:5,0 -f S16_LE -r 48000 -c 1 -d 7 -t wav | \
  sox -t wav - -t wav output.wav highpass 300 lowpass 7000 rate -v 16000 norm -3
```

Экономит шаг и место на диске, но менее удобно для отладки.

## Как выбрать порог highpass

Если сервер шумит сильнее обычного:
- `highpass 200` — мягче, но часть гула останется
- `highpass 300` — **рабочее значение** (проверено)
- `highpass 400` — жёстче, может «съесть» часть мужского голоса (низкие форманты)

## Типичные проблемы

### RMS упал после обработки < 0.01
Слишком агрессивные фильтры. Уменьшить `highpass` или убрать `norm -3`.

### ASR выдаёт «кнотка» вместо «кухня»
Форманты «х» и «н» съедены. Уменьшить `highpass` до 200 или убрать `lowpass`.

### Запись с 5 метров работает
При проверенном пайплайне ASR вытягивает речь с 5 метров даже на дешёвом USB-микрофоне. Если не работает — проверьте, что фильтры применены и микрофон на USB 2.0.
