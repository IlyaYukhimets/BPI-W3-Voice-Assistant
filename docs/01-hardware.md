# Железо

## Плата
- Banana Pi BPI-W3, RK3588, 8 ГБ RAM, 32 ГБ eMMC
- NPU: 6 TOPS, драйвер встроен в ядро (RKNPU 0.9.2)
- USB: 2× USB 3.0, 2× USB 2.0, 1× USB-C (OTG/Maskrom)
- Питание: DC 12V/2A **обязательно стабильное** — слабое питание приводит к сбоям PCIe/Ethernet

## Подключения
- **Аудио-выход:** 3.5 мм JACK, кодек ES8316 (card 3)
- **Аудио-вход:** USB-микрофон (Bus 001, USB 2.0 порт — не 3.0!)
- **UART:** USB-UART адаптер, скорость 1500000 бод, GND-TX-RX

## Проверенные проблемы
- ❌ USB 3.0 порт даёт больше помех → использовать USB 2.0
